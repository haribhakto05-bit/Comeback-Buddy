# Comeback

Your dreams, daily habits, workouts and a fresh line every morning. Built to bring you back when you slip.

## Deploy on Vercel

1. Create a new repository on GitHub called `comeback`.
2. Upload every file and the `icons` folder from this zip (Add file → Upload files). Keep the same folder structure.
3. Go to vercel.com → Add New → Project → import the `comeback` repo.
4. Framework preset: **Other**. No build command. Click **Deploy**.

## Install on your phone

- **Android (Chrome):** open your Vercel link → menu ⋮ → **Install app** / **Add to Home screen**.
- **iPhone (Safari):** open the link → Share → **Add to Home Screen**.

It opens full screen with the Comeback logo and works offline.

## Good to know

- Your ticks, dreams and Defender photos are saved on your phone only. Clearing browser data deletes them.
- After you change `index.html`, change `VERSION` in `sw.js` (e.g. `comeback-v2`) so phones get the update.
